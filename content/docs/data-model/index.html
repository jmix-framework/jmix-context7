Data Model

Data model is an essential part of any business application.

In Jmix, the application data is represented by entities. An entity can be stored in an external storage or exist purely in memory. In both cases, an entity is associated with a data store, which is an abstraction over a data source in Jmix applications.

An entity can have references to other entities, even if they are from different data stores. It allows you to create an integral data model comprising data from multiple relational databases or even from sources of different nature, like no-SQL databases or REST APIs.

See also the Key Features section to learn about Jmix data model concepts.
