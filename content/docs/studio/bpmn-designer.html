BPMN Modeler

Studio provides BPMN Modeler that allows you to model business processes in the IDE. The Modeler appears only when the BPM add-on is added to the project. See the description of the BPMN Modeler in Studio.

This feature requires a BPM subscription. If you don’t have the subscription, see the Enterprise+BPM Trial section to learn how to get a trial version.
