Superset

The Superset add-on is designed to integrate Jmix applications with Apache Superset. It provides the SupersetDashboard component and related functions that allow you to embed dashboards created in Apache Superset into application views.

In order to display a dashboard in your application, all you need to do is configure the Superset URL and credentials, and add the SupersetDashboard component to a view.

Installation

For automatic installation through Jmix Marketplace, follow instructions in the Add-ons section.

For manual installation, add the following dependencies to your build.gradle:

implementation 'io.jmix.superset:jmix-superset-starter'
implementation 'io.jmix.superset:jmix-superset-flowui-starter'
