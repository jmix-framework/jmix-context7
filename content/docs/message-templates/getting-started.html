Getting Started

This guide shows how to use the Message Templates add-on in a sample application for booking office rooms. After a booking is created, the user receives a templated message by email or through an in-app notification.

Follow these sections to build the sample application step by step:

  • Setting Up the Booking Application — build the sample booking application with CRUD views.

  • Template Definition — create reusable subject and body templates with configurable parameters.

  • Using Message Templates for Email — send email messages generated from templates.

  • Advanced Notifications with Message Templates — use templates for in-app notifications.
