User Interface

After installing the add-on, a new BPM section appears in the main menu. Here is a short description for each view.

To access the views, users must be granted appropriate Resource Roles:

  • BPM: process actor – grants access to Start process and My tasks allowing users to start processes and work with their assigned tasks.

  • BPM: administrator – grants full access to all BPM views and management features.
View Description

Start process

Starts a new process instance based on available process definitions.

My tasks

Displays tasks assigned to the current user and allows managing and completing them.

Modeler

Provides a web-based BPMN editor for creating and modifying process diagrams.

Process Drafts

Lists all available process drafts and shows a preview for each.

Process definitions

Lists deployed process definitions and details for each.

Process instances

Shows running and completed process instances with their current state.

User groups

Manages user groups used for task assignment and access control.

User tasks

Provides an overview of all user tasks across processes.

Decision tables

Displays available decision tables used in process logic.

Decision table modeler

Allows creating and editing decision tables.
