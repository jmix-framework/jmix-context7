User Interface

After installing the add-on, a new BPM section appears in the main menu.

See the respective article to learn about each view:

  • Start process

  • My tasks

  • Modeler

  • Process definitions

  • Process instances

  • User groups

  • User tasks

  • Decision tables

  • Decision table modeler

To access these views, users must be granted appropriate roles:

  • BPM: process actor — to access the Start process and My tasks views.

  • BPM: administrator — to access all views.
