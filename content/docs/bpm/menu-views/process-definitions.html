Process Definitions

The Process Definitions view displays a list of deployed process definitions.

Process Definition List

The following actions are available:

  • Filter – Filter definitions by name or key and choose whether to display only the latest version of each definition.

  • Open in modeler – Load the selected definition in the Modeler for editing.

  • View details – Open the Process Definition Details view.

  • Start process – Start a new instance of the selected process definition.

  • Upload BPMN XML – Deploy a process definition from a BPMN XML file.

Process Definition Details

The Process Definition Details view displays the definition properties, BPMN XML, and active process instances.

The following actions are available:

  • Version – Select another version of the process definition.

  • View process instance – Open the selected active process instance.

  • Suspend – Prevent new instances from starting from the selected definition. In the confirmation dialog, you can also suspend its active instances. Tasks from suspended instances do not appear in My tasks, and their timers and jobs stop running.

  • Activate – Reactivate a suspended definition. In the confirmation dialog, you can also reactivate its suspended process instances.

  • Migrate all process instances – Start process instance migration.

  • Delete deployment – Delete the deployment containing the selected version of the process definition.

    Deleting a deployment also deletes its associated process instances, history, and tasks.
