User Tasks

The User Tasks view displays all active user tasks across process instances.

User Task List

The following actions are available:

  • Filter – Filter tasks by process definition, assignee, candidate user, or candidate group, and then click Apply.

  • Reassign task – Reassign the selected task to another user.

  • Open process instance – Open the process instance associated with the selected task.

The list is empty by default. To load all tasks, click Apply without specifying filter conditions.
